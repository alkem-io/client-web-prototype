# Template plates

Drop photographed device plates here as `.jpg` or `.png`, then calibrate them at
`/mockups/calibrate`. Reference them from a composition as
`/mockup-templates/<filename>`.

A plate should be the flattened photograph with the device screens blank — the
generator maps the live screen onto the corners you calibrate, so whatever is
printed on the screen in the source image will be covered.

Keep the licence note with the plate: `registry.ts` has a `credit` field for it.

    How other whiteboards group tools

    The brief asks whether a grouped button is a menu, or a button that changes what it does. The tools we get compared to do both, and keep the timer and reactions away from the drawing tools.

    Questions for the next round

    1. What goes on key 9? With frame in "more tools", the bar has eight numbered tools. Key 9 could stay free, go to frame after all, or open reactions.
    2. Which shapes go in the group? Rectangle, ellipse and diamond. Diamond is the one the brief calls rarely used; it could leave for "more tools".
    3. One timer per board, or one per person? Today everyone can start their own, and they stack up in the corner. One shared timer that anyone can start or stop is easier to follow in a workshop.
    4. Show the timer and reactions box when you are alone on the board? Today reactions only appear once a second person joins. This round shows the box whenever you can edit, so a facilitator preparing a session can find it.

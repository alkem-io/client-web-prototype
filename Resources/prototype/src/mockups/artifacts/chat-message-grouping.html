Calmer chats: group messages, show fewer times

Today every chat message carries its own "3 hours ago" line, so a few short messages in a row take twice the room they need. This page shows one conversation four ways: as it looks now, and with the time in three different places. Everything else (grouping, day separators, reactions) is the same in all three, so you can judge the time on its own.

Production already does part of this. In group chats the avatar and name only show on the first of several messages in a row from one person. What is missing is everything to do with time. Hover a message on desktop, or tap it on the phone, to see its exact time.

How it looks in production today

A time line under every message, written as "2 hours ago". There are no day separators, so the only way to tell Friday from today is to read those lines.

Messages from one person are already joined up in group chats, but only by sender. Time is never looked at, so a message from Friday and one from today can end up in the same group.

Option A · like WhatsApp

A small time inside every bubble

The time sits in the bottom corner of each bubble, on the line it already uses. It costs no extra room, and every message shows its time without hovering or tapping.

  • Works the same on desktop and phone.
  • Still a time on every message, just smaller. The ticket asks for one time per group, so this one does not meet it.
Misses "one time per group"

Option B · like Teams and Messenger

One time under each group

A group is closed by a single time. Within a group the messages are minutes apart, so one time covers all of them. For the exact time of one message, hover it on desktop or tap it on the phone.

  • Meets every acceptance criterion on its own, with no extra dividers needed.
  • Never hides when someone spoke, which matters in a work chat ("did she say that before or after the meeting?").

Option C · like iMessage

Times only after a pause

No time near the messages at all. Each day starts with its separator and the first time ("Today 09:12"). After an hour of quiet, a small time divider marks where the conversation picked up again. Everything else is hover or tap.

  • The calmest of the three.
  • Hides too much for a work tool. In a busy hour you can't tell 09:13 from 10:55 without tapping.

The ticket's open questions, with a suggested answer

Where the time sits

Option B: one time under each group

It's the only one that meets "one time per group" without hiding time. A shows too many times and C shows too few.

Grouping rule

5 minutes, counted from the previous message

Counting from the previous message rather than the first one keeps a quick back-and-forth from being split in the middle. A new day always starts a new group.

Time divider after a pause

Only with option C

With B, every group already carries its time, so a divider after an hour would show the same time twice. Day separators are enough.

Avatar and name in 1-to-1

Not at all

The header names the person and there is only one other sender, so this is what production does already. Switch to "1-to-1 chat" above to see it.

Reactions

On the bubble's bottom edge

Overlapping the edge keeps a group together. The add-reaction button stays where it is now, appearing on hover next to the bubble.

Not part of this

  • Space chat. It's a prototype-only screen that already groups messages its own way.
  • Read receipts and "seen" markers. They don't exist on the platform.
  • The conversation list. Its "last message" times stay as they are.
